# Pixel-Programming-Language
Pixel programming language made using javascript.

Pixel Programming Language instructions-

Press the enter key to start.

instructions to save and open a sheet-
Open a sheet-
mode open 00001 Press -key(minus key)(00001 is sheet number)

Save a sheet-
mode save Press -key(minus key)

Press `key(which is this ~ key on the keyboard) to display the sheet data on the webpage after saving that sheet.

Copy this data into a array named t2data2 and save it with the file name data.js
Copy the data of new sheets in this array without deleting the previous data.
If a sheet needs to be deleted find the sheet using the sheet symbols in the Pixel Programmming Language.html program code.
See the code using notepad. Use notepad for all the above functions.

Keys which can be used are z=0z, x=0x,up arrow=01, down arrow=02, right arrow=03, left arrow=04.

All the variables are global variables.
var is used to declare a variable for your program.
00001 is the variable name.
Variable names should add by 1 and go till 99999. Example- 00001, 00002, 00003, 00004 and so on.
The data of the variable is number only and give by 5 numbers to make a number. Example- 00015 is the number 15.
Use ifvariable1nameifvariable2name and write data after it and use close identifier to close the if condition.
add is for addition, sub is for subtraction, mul is for multiplication, div is for division and equ is for equal.
Use variable names with keys. Example- k0zis00001
Use only variable names in operations which are functions.
Variable values can only be use with var.

Comments cannot be used because of the identifier keywords like var, if, add, x, y, r, g, b, k, etc.

If a part of the code is written wrong then that part of the code will not be executed in the output.

Use the / key to change between modes.

There is no need of spaces in the sheet or program.

Press = key to run and see the output of all the sheets.

Press Shift key for next page. Press ; key to go back to a page.

Press ' key to save the text of the program.

Press ] key to save more than one pages and download them.
